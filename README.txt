 🍅 AI-Powered Detection of Tomato Leaf Disease 

 📌 PROJECT OVERVIEW:

       This project is a Tomato Disease Detection System that uses a Convolutional Neural Network (CNN) to identify common diseases affecting tomato plants. 
       The model processes leaf images and predicts the type of disease to assist farmers in early diagnosis

       Project Name: AI-Powered Detection of Tomato Leaf Disease 
       Deployed on: Streamlit Cloud
       App URL: [leafscan.streamlit.app](https://leafscan.streamlit.app)


🔧 Steps for Installing the Project

	1.Download the project files from GitHub: siddhu2708/leafscan.

	2.Install Python 3.10+ on your system.

	3.Open an editor like PyCharm or VS Code after downloading the files.

	4.Create a new folder and upload all the downloaded files from GitHub into it.

	5. Open a terminal in the project directory and install all dependencies using:

		"pip install -r requirements.txt"
  
🔧 Steps to Run the Project

	1.Open a new terminal in the project directory.

	2.Run the following command:

		"streamlit run app.py"

	3. Choose any browser to open the Streamlit app, and the project will run successfully.
